# CampusEats Task Tracker

CampusEats Task Tracker is a small repository used to practise a professional GitHub workflow with feature branches, pull requests, issues, code review, continuous integration, and secure coding.

## Project structure

- `src/tasks.js` contains the sample task and total-calculation logic.
- `.github/workflows/ci.yml` validates the repository on pushes and pull requests.

## Run locally

```bash
npm test
```

## Security

Secrets must be supplied through environment variables or a managed secrets store. They must never be committed to the repository.
